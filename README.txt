========================================
  QRS - 2nd Round Assessment Platform
========================================

HOW TO RUN:

1. Extract this zip
2. Open terminal / PowerShell in the folder
3. Run:

   python -m http.server 8080

4. Open browser:  http://localhost:8080

========================================
WHAT'S NEW (Design)
========================================
- Completely new look (not like walk-in portal)
- Dark professional header
- Teal / green accent color (QRS branding)
- Clean modern cards & typography
- Distinct from typical assessment portals

FEATURES
- Role-based: Salesforce, PC, Integration, Testing, Database, Infra, WordPress, HR, Finance
- Levels: Fresher / Intern / Experienced
- Exactly 100 marks every time
- Voice questions only for HR & PC
- Coding answers require minimum 50 characters
- Live camera + face presence monitoring
- Tab minimize detection with 3-flag system
- Admin can review & free candidates
