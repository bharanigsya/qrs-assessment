QRS Assessment - How to start (Windows)
=======================================

1. Install once:      pip install -r requirements.txt
                      winget install --id Cloudflare.cloudflared
2. Double-click:      START-SERVER.bat      (keep this window open)
3. Double-click:      START-TUNNEL.bat      (keep this window open too)
   (or just double-click START-ALL.bat to do 2 + 3 together)
4. Copy the https://xxxx.trycloudflare.com address from the tunnel window.
5. Open  https://xxxx.trycloudflare.com/admin.html  and log in.
   (Opening admin on localhost also works: it will show a bar asking for
    the public address, or fill it in automatically when the tunnel runs.)
6. Create a candidate and copy the link. Links start with the public address.

SCHEDULED TESTS (e.g. 10:30)
- The test opens at the scheduled time and the server also refuses an early start.
- Times in emails now include the timezone; check it matches the candidate's.
- Changing the schedule in Admin -> Edit now moves the expiry automatically
  (expiry = new start + link validity). Check "Link expires" before saving.
- Before the test: make sure the PC will NOT sleep (Windows: Settings ->
  System -> Power -> Screen and sleep -> "Never" while plugged in).

IMPORTANT
- The tunnel address changes every time you restart START-TUNNEL.bat, and old
  links stop working. Create candidate links AFTER the tunnel is running, and
  resend (Admin -> Resend) if you ever restart it.
- Your PC must stay on, awake and online while candidates take the test.
- Candidate data is saved in the "data" folder. Use Admin -> Backup regularly.
- Change the default admin password after first login (Admin -> Settings).
  To seed a different first-run password, set QRS_ADMIN_PASSWORD and
  QRS_COORD_PASSWORD before the very first start.
