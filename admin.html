Security & Settings

Data Backup

All data currently lives in this browser's storage only. Download a backup regularly — clearing browser data or using a different browser/device loses everything not backed up.

Backend Connection

Checks whether this page can reach . If candidates on other devices see "Invalid or Expired Link" for real, unexpired links, run this first — it usually means BACKEND_BASE near the top of this file needs to point at your backend's URL.

Email Delivery (auto-send links)

Checks whether the backend can send emails. Configure SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS, and optionally SMTP_FROM_NAME/SMTP_FROM_EMAIL as environment variables on your host (Render → your service → Environment). Works with a Gmail App Password, Outlook, or any SMTP provider. Manual "Copy Link"/"Email Link" always work regardless of this.

Notifications

Get a desktop notification the moment a candidate completes or gets flagged, while this admin tab is open. True unattended email alerts need an SMTP-connected backend — ask me to wire that up if you get mail server credentials.
